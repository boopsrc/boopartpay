Demonstração

Reconhecimento facial
em tempo real

Como uma câmera comum vira um mapa de pontos do rosto.

Use ← → (ou os botões abaixo) para navegar.

Pipeline

Do quadro de vídeo aos pontos

1

Captura

A câmera entrega quadros (frames).

2

Detecção

Um modelo leve encontra cada rosto no quadro e devolve uma caixa delimitadora.

3

Landmarks

Para cada rosto, um modelo de landmarks estima pontos de referência sobre a face. Exemplos: Google ML Kit (contornos), MediaPipe Face Mesh (478 pontos), dlib (68 pontos), InsightFace.

4

Contornos

Os pontos são agrupados por característica: oval do rosto, olhos, sobrancelhas, lábios…

Detecção de contorno

Uma lista de pontos por característica

Com a detecção de contorno ativada, cada rosto detectado vem com uma lista de pontos para cada característica facial. Esses pontos desenham a forma do recurso.
